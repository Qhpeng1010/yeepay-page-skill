# 开放平台视觉宪法

## OP-VIS-001 品牌气质

开放平台服务企业客户和开发者，应呈现专业、开放、可靠和可检索的气质。品牌主色为 `#1162E6`，只用于当前导航、主操作、链接和流程路径；禁止用高饱和色铺满业务正文。

## OP-VIS-002 双 Shell

官网使用 Marketing Shell：`60px` 主导航、最大 `1200px` 内容容器、Hero 到能力/流程/CTA 的叙事。文档使用 Documentation Shell：`60px` 主导航 + `52px` 二级导航 + `256px` 左目录 + 正文 + `150px` 本文目录。两种 Shell 共用 Token，不共用信息密度和布局。

## OP-VIS-003 排版与留白

中文使用 PingFang SC 系统字体栈；正文 `14px/22px`，文档 H1 `32px`，H2 `24px`，H3 `20px`。正文以阅读列宽为准，章节间距 `40px`；官网模块上下留白使用 `80px-120px`。Montserrat 只用于少量品牌化英文或数据。

## OP-VIS-004 表面与组件

页面以白色为底，轻灰 `#F7F7F7` 用于内容分区，浅蓝 `#EDF4FC` 用于信息提示。按钮与输入框 `4px` 圆角，普通卡片 `8px`，营销卡 `16px`；阴影只用于轻分层。代码块使用明确的深浅对比和等宽字体，参数表必须可横向滚动。

## OP-VIS-005 响应式

`>=1280px` 使用完整三栏文档；`1024px-1279px` 收缩页边距；`768px-1023px` 隐藏本文目录；`<768px` 目录改抽屉，正文单列。不得缩放桌面稿来代替重排。

## OP-VIS-006 视觉冲突

API 准确性和阅读可达性 > 交互验收 > 本视觉宪法 > 页面模板 > 组件默认样式。
