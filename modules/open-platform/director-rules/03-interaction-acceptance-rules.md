# 开放平台页面交互与验收规则

## OP-INT-001 信息层级

文档页顺序为面包屑、H1、摘要/适用范围、流程概览、正文 H2/H3、代码或参数、错误处理、相邻文档。左侧目录解决“去哪里”，本文目录解决“读到哪里”，正文解决“如何完成”。

## OP-INT-002 文档导航

当前左侧目录必须唯一高亮且路径自动展开。锚点滚动需预留顶部 `112px` 导航高度，本文目录随当前章节更新。窄屏隐藏或转移本文目录，不能遮挡正文。

## OP-INT-003 代码与参数

代码块必须有语言/格式标签和复制操作；复制成功有短反馈，失败要说明恢复动作。参数表必须有字段名、类型、是否必填和说明；窄容器支持横向滚动。

## OP-INT-004 状态与反馈

搜索、目录加载、代码复制和文档反馈都要有 Loading、Success、Error 或 Empty 的清晰文案。无结果提供关键词调整、分类入口或热门文档，不显示空白页面。

## OP-INT-005 无障碍

导航、折叠、锚点、复制和目录必须可键盘访问；当前态不能只用蓝色表达；H1-H3 必须按语义层级输出。

## OP-INT-006 验收案例

| 规则 | 场景 | 通过条件 |
| --- | --- | --- |
| OP-INT-002 | 左侧目录和本文目录点击 | 滚动至目标章节，当前项唯一明确 |
| OP-INT-003 | 复制请求示例 | 有成功反馈，代码内容保持不变 |
| OP-INT-004 | 搜索 `ERROR` / 无匹配 | 分别显示错误和空结果恢复入口 |
| OP-INT-005 | 键盘 Tab 导航 | 链接、按钮、目录均能获得清晰焦点 |
| OP-VIS-005 | 1440px / 1024px | 桌面三栏完整，1024px 隐藏本文目录 |

## OP-INT-007 冲突裁决

接口准确性、任务路径和无障碍优先于视觉装饰；一切未验证的交互保持 shadow 或 legacy。
