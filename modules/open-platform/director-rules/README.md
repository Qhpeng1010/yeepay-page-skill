# Open Platform Director Rules

这是易宝开放平台的独立页面决策层，适用于官网、文档中心、API、SDK、错误码和接入指南。

## 边界

- 只使用开放平台的品牌、Marketing Shell 和 Documentation Shell。
- 不使用 Boss Ledger 或 Easy Account 的后台导航、卡片密度、表格样式和执行器。
- 页面由业务意图先选择 Marketing 或 Documentation Shell，再选择一个主页面族。

## 决策与冲突

开发者完成任务的路径、API 准确性和无障碍优先于视觉；交互验收规则优先于模板默认值；视觉宪法优先于基础组件默认样式。未声明的能力保持 legacy 或 pending。

规则 ID：`OP-VIS-*`、`OP-TPL-*`、`OP-INT-*`。
