# Open Platform Page Spec Core Context

- `OP-VIS-*` defines the developer-portal visual constitution.
- `OP-TPL-*` selects Marketing or Documentation Shell and prevents mixed templates.
- `OP-INT-*` controls task completion, navigation, code behavior, accessibility and acceptance.
- API document Page Spec fields must be factual product content; renderer does not invent API names, parameters or error codes.
