# Template Routing Spec

## Purpose

本文件只保留跨系统的路由边界，不定义任何系统的页面模板、字段数量阈值、页面组合或布局细节。

业务系统的页面家族、模板选择、组合限制和禁用组合，必须来自已路由系统自身的模板与应用规则。

## Hard Rules

- 每个交付必须有一个可追溯的主页面方案。
- 页面作者只能使用当前系统已发布且当前策略允许的页面能力。
- 不得从共享模板、历史 Change 或其他系统拼接新的页面结构。
- 不能满足的组合必须报告能力缺口，不得以手写页面绕过。

## Required Output

页面设计记录应写明主页面方案、选择原因、被拒绝方案、当前能力状态和规则引用。
