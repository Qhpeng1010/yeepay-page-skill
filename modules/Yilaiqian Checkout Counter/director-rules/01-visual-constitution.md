# 易来钱收银台视觉宪法

## YLQ-VIS-001 交易优先级

页面气质应直接、克制和可信。金额是付款页唯一最高视觉重点，主色 `#0051FF` 只用于付款操作和选中态；同屏只允许一个主操作。

## YLQ-VIS-002 移动画布

以 `375x812` 为基准但不固定宽高。页面使用 `#F0F0F0` 底色和本域 `01背景.png`，主内容左右 `12-16px`，宽度超过 `430px` 时居中并限制支付面宽度。必须使用安全区，不复制假状态栏。

## YLQ-VIS-003 文字与表面

字体使用 PingFang SC 系统栈。导航标题 `17px`，正文 `14px`，动作 `16px`，金额输入 `36px`，结果金额 `32-36px`。任务组使用白色 `12px` 圆角卡片和 `16px` 内边距；不用重阴影和强分割线。

## YLQ-VIS-004 组件气质

- 金额区保持逻辑焦点，输入后才显示清除入口。
- 支付方式用 Vant RadioGroup 单选，整行可点，不能伪造渠道图标。
- 数字键盘、密码抽屉、处理中 Overlay、结果详情和完成操作必须分别使用 Vant NumberKeyboard、Popup、PasswordInput、Overlay/Loading、CellGroup/Cell 和 Button。
- 状态必须结合图标、标题与说明，不能只靠绿色或红色。

## YLQ-VIS-005 响应式

`375px` 与 `430px` 下不能出现横向滚动；键盘固定在移动支付面底部且不遮挡金额或密码状态。小于 `375px` 只收缩空白，不降低触摸面积和基础字号。

## YLQ-VIS-006 视觉冲突

交易安全与可用性优先于视觉；本宪法优先于 Vant 未约束默认值。禁止用 CSS 渐变替换本域背景资产。
