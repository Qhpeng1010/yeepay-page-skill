# 易来钱收银台 Director Rules

这是易来钱移动 H5 收银台的独立决策层，覆盖扫码付款、金额输入、支付方式、密码确认、处理中、支付结果和异常恢复。

## 边界

- 只适用 375px 基准的移动交易体验，使用本域背景资产、Vue 3 与 Vant 4。
- 不使用 Boss Ledger、Easy Account 或开放平台的桌面导航、表格、卡片和确认模型。
- 所有支付控件必须由 Vant 组件实现；Page Spec 只声明业务内容和允许能力。

## 冲突裁决

交易安全和资金正确性 > 状态机与交互验收 > 移动视觉宪法 > 模板默认值 > Vant 默认样式。未验证的交易能力必须保持 shadow 或 legacy。

规则 ID：`YLQ-VIS-*`、`YLQ-TPL-*`、`YLQ-INT-*`。
