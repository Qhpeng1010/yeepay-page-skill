# Easy Account Template Index

Easy Account 使用本模块自己的 Markdown 页面模板。

- 框架规范：`templates/template-01-framework.md`
- 查询列表：`templates/template-02-query-list.md`
- 业务概览：`templates/template-03-dashboard.md`
- 新增/编辑表单：`templates/template-04-form.md`
- 详情：`templates/template-05-detail.md`
- 处理结果：`templates/template-06-result.md`

每次只选择一个主内容模板，并始终同时读取框架规范。不得使用 Boss Ledger 模板作为历史参考源。
