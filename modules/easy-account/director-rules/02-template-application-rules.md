# 易账通模板与应用规则

## EA-TPL-001 页面家族

| 页面族 | 解决的问题 | 本域模板 |
| --- | --- | --- |
| List | 按条件查找并批量扫描账户或账务记录 | `template-02-query-list.md` |
| Form | 新增、编辑、开户、调账等录入任务 | `template-04-form.md` |
| Detail | 阅读对象身份、余额口径、关联记录和日志 | `template-05-detail.md` |
| Result | 展示一次受控处理的成功、处理中或失败结果 | `template-06-result.md` |
| Dashboard | 展示有明确时间范围和口径的业务概览 | `template-03-dashboard.md` |

每次只选择一个主页面族。框架模板只定义本域导航和工作区，不得借用其他系统壳层。

## EA-TPL-002 模板选择

- 查询字段不超过 6 个且无统计卡片时使用普通查询列表。
- 字段超过 6 个、筛选有条件依赖或需分组时使用高级查询列表（初期保持 shadow）。
- 字段少且无前后依赖可用简单表单；字段多或有业务语义分组时使用分组表单。
- 有前后依赖、材料上传或复核环节时使用步骤表单（初期 legacy）。
- 详情信息少且需要保留列表上下文时可用抽屉；字段多、含关联记录或操作日志时使用独立详情页。
- 处理结果必须说明影响对象、金额、币种、业务单号和恢复路径。

## EA-TPL-003 页面组合

- 列表新增：字段少、无需离开上下文时用弹窗；中等字段量用抽屉；长表单或上传复核用独立页。
- 详情少用抽屉，详情多用独立页；不得在抽屉里塞入完整步骤流。
- 查询区、结果区必须是同层独立业务面；统计属于结果区内部，不单独成为第三块业务卡片。

## EA-TPL-004 禁用组合

- 分组表单不得叠加右侧说明配图或第二个主表单。
- 步骤表单不得与弹窗表单组合；步骤之间不得跨未完成步骤直接提交。
- 详情页不得把所有字段渲染成可编辑控件；可变更账务的动作不能藏在普通文本链接中。
- 金额摘要不得脱离币种、口径和时间范围单独展示。

## EA-TPL-005 能力边界

首个迁移批次只验证普通查询列表、列设置和状态确认操作。高级统计列表、表单、详情、结果、Dashboard 和独立空状态保持 shadow、workflow-only 或 legacy，直到有对应黄金案例和浏览器证据。
