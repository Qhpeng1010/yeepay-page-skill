# 易账通页面交互与验收规则

## EA-INT-001 信息层级

页面顺序固定为页面标题/口径说明、查询条件、结果摘要、列表工具栏、表格、分页、浮层反馈。标题说明“看什么”，摘要说明“按什么口径”，筛选决定“查什么”，表格负责“比较”，操作只服务于当前行或当前任务。

## EA-INT-002 查询流程

查询必须显示加载状态并阻止重复提交；重置恢复默认条件并刷新结果；无匹配结果保留表头与筛选条件；错误状态说明原因并提供重试。查询完成后停留在当前列表，不弹出无关成功弹窗。

## EA-INT-003 保存与流转

保存成功后：短任务返回列表并保留可核对摘要，长任务进入结果页；关闭或返回前若有未保存修改必须二次确认。步骤完成后只能进入下一步或明确结果页，不用模糊 Toast 代替关键结果。

## EA-INT-004 状态与权限

加载、空、错误、成功、处理中和无权限必须有独立语义。无权限时不渲染可执行操作；敏感字段明文展示需独立权限。状态不能只靠颜色表达。

## EA-INT-005 危险操作

冻结、解冻、调账、关闭和解绑等操作必须二次确认，确认文案说明对象、影响和不可逆性。确认期间禁止重复提交，成功后更新行状态并给出可核对反馈，失败时保留原状态并提示重试或联系路径。

## EA-INT-006 响应式交互

小于 `1280px` 时查询条件折为两列，表格允许横向滚动；核心查询、重置和行主操作仍必须可见。任何响应式变化不得改变字段含义、金额口径或权限边界。

## EA-INT-007 验收案例

| 规则 | 场景 | 通过条件 |
| --- | --- | --- |
| EA-INT-002 | 正常查询、重置、无结果、`ERROR` 错误 | 四种状态均可见且流程不跳离列表 |
| EA-INT-004 | 无权限账户 | 不出现冻结/调账等执行按钮，字段继续脱敏 |
| EA-INT-005 | 点击冻结并取消/确认 | 取消不变更，确认只变更目标行且有反馈 |
| EA-VIS-006 | 1280px 与 1024px | 查询从四列变两列，表格可滚动，按钮不溢出 |
| EA-TPL-003 | 列设置 | 仅通过工具按钮打开，关闭后表格列稳定无跳动 |

## EA-INT-008 冲突裁决

本文件的安全、权限和流程规则优先于视觉和模板规则；视觉宪法优先于组件库默认样式。所有无法由规则证明的行为保持 legacy 或 pending。
