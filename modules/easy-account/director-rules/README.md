# Easy Account Director Rules

这是易账通唯一的页面决策层，负责把业务需求转换为可执行的页面族、能力和验收规则。

## 适用范围

- 只适用于 Easy Account / 易账通的账户、账务、余额、调账、对账和操作记录页面。
- 规则来源包括本目录、`design.md`、`business-rules.md`、`components.md` 和本域模板。
- 不读取、不复制 Boss Ledger 的 Shell、主题色、Logo、模板实现或 Page Spec 运行时。

## 决策顺序

1. 先确认业务对象、权限和金额口径。
2. 再选择一个主页面族和本域模板。
3. 仅声明策略中允许且已验证的能力。
4. 通过契约、生成产物完整性和浏览器场景验收后才能交付。

## 规则冲突

业务安全和权限规则优先，其次是本目录的交互规则，再其次是视觉规则，最后才是模板默认值。任何未声明或未验证的能力都必须保留在 legacy 或标记为 pending。

## 规则 ID

- `EA-VIS-*`：视觉宪法
- `EA-TPL-*`：模板与应用规则
- `EA-INT-*`：页面交互与验收规则
