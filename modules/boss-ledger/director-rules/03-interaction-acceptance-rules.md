# 老板管账页面交互与验收规则

## 信息优先级

**BL-INT-001** 按任务依赖关系排列信息：页面上下文、必要摘要、查询或输入、主要结果、行级或后续操作、补充说明。统计和装饰不得把主要任务挤出首个有效视口。

**BL-INT-002** 查询操作属于查询表单，结果工具属于结果模块，行操作只作用于当前记录；未选中记录前，批量操作不可用。

## 查询与上下文

**BL-INT-003** 查询应应用明确的用户条件，并正确重置分页；重置应恢复声明的默认值、清除临时勾选并返回可预期的数据集；展开/收起必须保留已输入的值。

**BL-INT-004** 分页、排序、列设置、Drawer 查看和可恢复的失败状态应尽量保留当前列表上下文。关闭 Drawer 或 Modal 不能悄悄重置来源列表。

## 表单与工作流

**BL-INT-005** 提交应就近校验必填、格式、范围、依赖和权限。隐藏后失效的下游值必须清除，除非业务明确要求保留。

**BL-INT-006** 提交必须防止重复执行。失败时保留用户输入并说明恢复方式；成功时给出明确业务结果：关闭并刷新、返回来源、留在当前页继续新增、打开详情或进入结果反馈。

**BL-INT-007** 未通过前置条件不得进入下一步；返回上一步应保留有效输入；最终复核应只读，除非用户主动返回编辑。

**BL-INT-016** 独立简单表单页和带引导的简单表单，其操作区紧随最后一个字段，并与输入控件的起始线对齐；主按钮在前、辅助按钮在后，按钮之间保持 `16px` 间距，不使用固定底部操作栏。分组表单和步骤流程仍使用固定操作栏，避免长页面操作离开视口。

**BL-INT-017** 结果页的主操作必须引导用户回到来源、继续处理或查看后续记录，不能只提供无意义的关闭操作。结果信息区在操作之前；反馈为可选、非阻断操作，选择后只反馈确认，不改变结果状态或主操作可用性。

## 状态、权限与风险

**BL-INT-008** Loading、首次空数据、查询无结果、请求错误、无权限和缺少前置条件是不同状态，必须使用不同文案和恢复方式。

**BL-INT-009** 可见操作必须与记录状态一致，未知状态不能按正常状态处理。页面、字段和操作权限分别表达；前端的显示与隐藏不替代服务端授权。

**BL-INT-010** 危险或敏感操作确认前必须说明对象、影响范围、金额或数量（如适用）、是否可撤销和操作后的状态。高风险资金或身份操作可能需要强于确认弹窗的验证方式。

**BL-INT-015** Dashboard 的数据范围控件必须同时作用于全部指标和图表；页面首屏优先展示范围、核心指标和最重要趋势，分布与排行作为同一监控任务的补充。Dashboard 不得借用查询条件、结果表格或分页来承载逐条业务操作。

## 验收模型

**BL-INT-011** 每条硬规则至少由一个明确场景验收。没有可执行证据的清单，不能宣称已验证运行时行为。

| 场景 | 对应规则 | 前置条件 | 用户操作 | 期望证据 |
| --- | --- | --- | --- | --- |
| 基础列表查询 | BL-TPL-001、BL-INT-003 | 存在记录和查询字段 | 查询并重置筛选 | 契约通过、筛选后的 DOM、重置后的 DOM、分页状态 |
| 查询失败 | BL-INT-008 | 已声明失败触发方式 | 发起查询 | 显示错误状态与恢复操作，而不是 Empty |
| 列设置 | BL-TPL-016 | 存在可选列 | 隐藏、恢复并重置列 | 控件可操作；操作列仍可见 |
| Drawer 详情 | BL-TPL-009、BL-INT-004 | 来源列表存在记录 | 打开并关闭一行详情 | 显示正确记录；列表状态保留 |
| 独立页标题 | BL-VIS-019 | 存在独立表单页和独立详情页 | 查看当前 Shell Tab 和任务模块首屏 | Tab 显示业务页面名称；任务模块中不出现重复的页面级标题；分组时只显示业务信息组标题 |
| 带引导的简单表单 | BL-TPL-008、BL-VIS-020 | 存在资金、结算、开户或规则配置的单阶段表单 | 分别在桌面和窄屏查看 | 桌面端在最大 `1200px` 居中区域、左右各 `16px` 内边距内展示字段、默认引导插图、标题和说明；窄屏隐藏整个引导区，不影响表单与操作 |
| 表单布局 | BL-VIS-012 | 分别存在 6 项、7 项独立页，6 项 Modal，以及 8 项、9 项 Drawer；步骤表单存在不同字段数量的步骤 | 在桌面和窄屏查看表单 | 6 项及以下独立页/Modal 与 8 项及以下 Drawer 使用左右 Label/Input、字段单列；7 项及以上独立页与 9 项及以上 Drawer 使用 Label 在上、字段网格；步骤按当前步骤判断，窄屏均重排为 Label 在上、字段单列 |
| 简单表单操作区 | BL-INT-016 | 存在独立简单表单页和带引导的简单表单 | 查看字段末尾和页面底部 | 操作区紧随最后一个字段并与输入控件起始线对齐；主按钮在前、辅助按钮在后，间距 `16px`；页面底部没有固定操作栏；分组和步骤流程仍保留固定操作栏 |
| 基础结果页 | BL-TPL-021、BL-VIS-021、BL-INT-017 | 表单或步骤流程提交成功、失败、警告或处理中 | 完成流程并查看结果 | 页面居中显示状态图标、标题、解释和主操作；不显示右侧引导图或步骤插图；主操作具有明确后续目标 |
| 复合结果与反馈 | BL-TPL-021、BL-VIS-021、BL-INT-017 | 结果包含多项金额、数量或处理明细，或需要体验反馈 | 完成流程、查看信息区并选择反馈 | 结果信息区在操作前且使用两列低强调面板；可选反馈区位于操作后，选择反馈不阻断主操作 |
| 表单校验 | BL-INT-005 | 存在必填和格式字段 | 提交无效值 | 字段旁显示错误；不进入成功状态 |
| 提交恢复 | BL-INT-006 | 已声明失败状态 | 对失败路径提交有效数据 | 输入保留，显示恢复文案 |
| 步骤拦截 | BL-TPL-007、BL-INT-007 | 存在前后依赖步骤 | 未完成当前步时尝试前进 | 当前步校验通过前不可前进 |
| 危险操作 | BL-INT-010 | 存在不可逆操作 | 触发操作 | 确认内容说明对象、影响和结果状态 |
| Dashboard 范围与监控 | BL-TPL-002、BL-TPL-020、BL-INT-015 | 存在范围控件、指标、分布、趋势和排行 | 切换统计范围 | 指标与全部图表显示同一范围；页面不出现查询表格、分页或行操作 |

## 交付门禁

**BL-INT-012** Page Spec 交付必须同时通过以下检查：

1. 导演规则、策略、Schema、渲染器和 Shell 的哈希与发布清单一致。
2. Page Spec 的 Schema 和语义能力校验通过。
3. 生成文件与 Page Spec 及固定渲染器输入完全一致。
4. 固定 Shell 和系统资产检查通过。
5. 浏览器 DOM 渲染和非空截图检查通过。
6. 必需的中文文案、状态和已声明交互均存在。

**BL-INT-013** 任一门禁失败即阻止交付，不存在“带备注通过”。能力缺口必须报告为不支持，不能记录为成功页面。

## 反馈与规则变更

**BL-INT-014** 需求专属反馈优先修改 Page Spec；重复出现或具有通用性的反馈，应修改导演规则、策略、契约或渲染器，并补充回归覆盖。生成的 HTML、JavaScript 和 CSS 绝不是长期修复位置。
