# Proposal: YOP API 首页页面设计方案

## 1. Original Request

使用 yeepay-page-skill，帮我做一个 YOP API 首页的页面设计方案，不用写代码

## 2. Requirement Understanding

用户希望为 YOP 开放平台设计一个 API 首页，用于开发者快速发现 API 能力、查看接入入口、搜索接口文档、进入 API 详情和完成接入前置准备。

本次为 Design Only 模式，输出 `proposal.md` 和 `page-design.md`，不输出前端代码。

## 3. Target Theme

- Theme: yeepay-开放平台-DESIGN
- Reason: 需求明确包含 “YOP” 和 “API 首页”，属于开放平台、开发者中心和 API 文档类页面，应使用 `specs/themes/yeepay-开放平台-DESIGN.md`。

## 4. Background

YOP API 首页是开发者进入开放平台 API 文档和接入流程的核心入口。页面需要帮助开发者快速理解平台能力、定位目标 API、查看接入步骤，并进入接口详情、错误码、SDK 和示例代码等技术资料。

相比内部后台查询页，该页面更偏开发者文档和产品能力导航，需要优先保证阅读效率、搜索效率和接入路径清晰。

## 5. Goals

- 帮助开发者快速搜索和定位 YOP API。
- 展示高频 API 分类和推荐接入能力，降低首次接入成本。
- 提供接入流程、SDK、错误码、示例代码等关键入口。
- 明确 API 状态、环境、版本和更新信息，提升技术信任感。
- 引导用户从首页进入 API 详情页、接入指南或调试流程。

## 6. Users / Roles

- 开发者：查找 API、阅读接入说明、查看示例代码。
- 技术负责人：评估 API 能力范围、接入成本和稳定性。
- 解决方案人员：根据业务场景给商户或合作方推荐 API。
- 产品运营人员：维护推荐 API、公告、文档更新和能力分类。
- 平台管理员：管理 API 展示状态、版本和文档入口。

## 7. Scope

### In Scope

- API 首页信息架构。
- API 搜索入口。
- API 能力分类入口。
- 推荐或高频 API 模块。
- 接入流程入口。
- SDK、错误码、示例代码、更新日志等文档入口。
- API 状态、版本、环境等元信息展示规则。
- 空状态、加载状态、搜索无结果和异常状态说明。

### Out of Scope

- 不输出前端代码。
- 不设计具体 API 详情页全部内容。
- 不设计 API 在线调试器的完整交互。
- 不设计 API 管理后台。
- 不定义真实接口数据结构。
- 不处理用户权限系统和应用密钥创建流程的完整细节。

## 8. Business Object

业务对象：YOP API 能力与 API 文档入口。

核心对象包括：

- API 分类
- API 条目
- 接入指南
- SDK 资源
- 错误码文档
- 示例代码
- 文档更新记录

## 9. Core Workflow

1. 用户进入 YOP API 首页。
2. 用户通过搜索框输入接口名称、能力关键词或错误码。
3. 系统展示匹配的 API、文档和相关资源。
4. 用户可从 API 分类中进入目标能力，如支付、退款、分账、商户进件、对账等。
5. 用户可查看推荐 API 或高频接入能力。
6. 用户可进入接入流程模块，查看创建应用、获取密钥、沙箱联调、上线验证等步骤。
7. 用户可进入 API 详情页查看请求地址、参数、响应、错误码和示例代码。
8. 用户可进入 SDK、错误码、示例代码或更新日志等辅助文档。

## 10. Fields

| Field | Type | Required | Description | Example |
|---|---|---|---|---|
| API 名称 | String | Yes | API 展示名称 | 统一支付下单 API |
| API 标识 | String | Yes | API 唯一标识或接口编码 | yop.pay.order.create |
| API 分类 | Enum | Yes | API 所属能力分类 | 支付 |
| API 描述 | String | Yes | API 能力说明 | 用于创建一笔支付订单 |
| 请求方法 | Enum | No | API 请求方式 | POST |
| 接口地址 | URL | No | API 详情页展示的请求地址 | /rest/v1.0/pay/order |
| API 状态 | Enum | Yes | 当前 API 可用状态 | 可用 |
| 版本 | String | No | API 当前版本 | v1.0 |
| 适用环境 | Enum | No | 支持沙箱、生产或全部环境 | 沙箱 / 生产 |
| 更新时间 | DateTime | No | 文档或 API 最近更新时间 | 2026-07-08 10:00:00 |
| 推荐标识 | Boolean | No | 是否推荐在首页展示 | 是 |
| 相关资源 | Link[] | No | SDK、示例代码、错误码等链接 | Java SDK |

## 11. Status

| Status | Meaning | Available Actions |
|---|---|---|
| 可用 | API 当前可正常接入 | 查看文档、调试接口、申请接入 |
| Beta | API 处于试用或灰度阶段 | 查看文档、申请试用 |
| 即将下线 | API 已有替代方案，未来会停止维护 | 查看迁移说明、查看替代 API |
| 已下线 | API 不再支持新接入 | 查看历史说明 |
| 维护中 | API 暂时不可用或文档维护中 | 查看公告、稍后重试 |

## 12. Permissions

- 未登录用户：可浏览公开 API 分类、基础说明和部分接入指南。
- 已登录开发者：可查看完整 API 文档、SDK、示例代码和接入说明。
- 已认证商户或合作方：可申请接入、创建应用、获取密钥、进入调试流程。
- 平台管理员：可维护 API 展示状态、推荐排序、分类和文档更新。
- 敏感操作如获取密钥、生产环境开通、应用创建，不在 API 首页直接完成，应跳转到对应流程。

## 13. Edge Cases

- API 列表加载失败：展示错误提示和重试入口。
- 搜索无结果：展示空状态，并推荐检查关键词或查看全部分类。
- 分类为空：隐藏空分类或展示“暂无 API”说明。
- API 已下线：保留历史说明，不展示“申请接入”主操作。
- 用户未登录：涉及接入申请、调试、密钥相关操作时引导登录。
- 用户无权限：展示权限说明和申请入口。
- 文档更新异常：展示最近可用版本，并提示更新状态。
- 外部资源链接失效：展示错误提示，并提供反馈入口。

## 14. Acceptance Criteria

- 当开发者进入 YOP API 首页时，系统应展示搜索入口、API 分类、推荐 API、接入流程和辅助文档入口。
- 当开发者输入 API 名称或关键词搜索时，系统应返回匹配的 API 或文档资源。
- 当搜索无结果时，系统应展示空状态并提供查看全部 API 分类的入口。
- 当开发者点击某个 API 条目时，系统应跳转到对应 API 详情页。
- 当 API 状态为“即将下线”时，页面应展示状态标识和迁移说明入口。
- 当用户未登录并点击“申请接入”时，系统应引导用户登录。
- 当 API 数据加载失败时，页面应展示错误反馈和重试入口。
- 当页面展示 SDK、错误码、示例代码入口时，点击后应进入对应文档页面。

## 15. Assumptions

- 本需求明确指定 YOP，因此使用 YOP 主题。
- “API 首页”按文档中心页处理，并结合 API 导航首页能力；不按普通后台查询列表页处理。
- API 详情页作为跳转目标存在，但本次不展开完整详情页设计。
- YOP / YeePay Open Platform 主题视觉细节以 `specs/themes/yeepay-开放平台-DESIGN.md`、`specs/design-system.md` 和后续补充规则为准。
- 本次按用户要求不输出前端代码。
