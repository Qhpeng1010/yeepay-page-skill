# 需求方案：客户门店查询列表页

## 1. 原始需求

使用 yeepay-page-skill 生成一个客户门店查询列表页。必须读取指定 Boss Ledger theme routing、template routing、主题规范和查询列表模板；不重新设计页面，只替换业务字段、表格列、操作按钮和 mock 数据；输出 HTML 预览并执行 `validate-boss-ledger-preview.mjs`，校验失败需自动修正。

## 2. 需求理解

本次需求属于 Boss Ledger 后台的客户门店查询列表场景，服务客户运营、商户运营、客服和风控支持角色。页面用于按客户、门店、状态、地区、经营类型和创建时间查询门店档案，并支持查看详情、编辑入口、下载 Excel 和列设置。

合理假设：本次只输出 HTML 评审预览和 change 包文档，不修改生产工程代码。

## 3. 目标主题

- 主题：Boss Ledger
- Theme source: `specs/themes/boss-ledger.md`
- 选择原因：需求包含客户门店、查询列表、后台运营语义，按 `specs/theme-routing.md` 选择 Boss Ledger。
- Mixed Theme Sources: No

## 4. 业务目标

- 提供客户门店档案的统一查询入口。
- 支持客户编号、客户名称、门店编号、门店名称等高频检索。
- 支持按门店状态、所属地区、经营类型和创建时间筛选。
- 保留列表上下文查看门店详情。
- 支持列设置和下载 Excel，满足后台运营查询需要。

## 5. 使用用户 / 角色

| 角色 | 使用场景 | 核心诉求 | 主要操作 |
|---|---|---|---|
| 客户运营 | 日常维护客户门店档案 | 快速定位客户门店并查看状态 | 查询、查看详情、编辑 |
| 商户运营 | 检查门店资料和经营类型 | 查找门店归属客户和地区 | 查询、下载Excel |
| 客服支持 | 响应门店状态咨询 | 查询门店状态和负责人 | 查询、查看详情 |
| 风控支持 | 排查冻结或异常门店 | 按状态和地区定位门店 | 查询、查看详情 |

## 6. 业务范围

本期范围：
- 客户门店查询条件。
- 客户门店列表字段、状态和行内操作。
- 列设置、下载Excel、分页、loading、empty。
- 客户门店详情 Drawer。

非本期范围：
- 真实接口接入。
- 生产项目路由、权限和表单编辑流程实现。
- 新增页面模板或主题规则。

## 7. 业务对象

- 客户
- 门店
- 门店经营类型
- 门店状态
- 操作记录

## 8. 核心业务流程

1. 用户进入“客户门店查询”页签。
2. 输入客户或门店查询条件。
3. 点击“查 询”刷新列表。
4. 用户通过列设置调整列表字段展示。
5. 用户点击“查看详情”打开 Drawer 查看客户和门店信息。
6. 用户点击“编辑”获得进入编辑流程的反馈。
7. 用户可下载 Excel 用于线下核对。

## 9. 验收标准

- 页面使用 Boss Ledger 固定壳层和查询列表模板。
- 只替换业务字段、表格列、行内操作和 mock 数据。
- 查询动作区位于三列查询网格最右侧。
- 表格使用 Ant Design Table，分页在结果模块内。
- 操作列固定右侧，每行只有一个主操作“查看详情”。
- HTML 预览通过 Boss Ledger 校验脚本。
