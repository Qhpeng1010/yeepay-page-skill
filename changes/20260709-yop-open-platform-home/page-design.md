# Page Design: 易宝支付 YOP 开放平台首页页面方案

## 1. Selected Page Template

- Template: 文档中心页扩展 / 开放平台门户首页
- Reason: 该页面属于 YOP 开放平台首页，目标是分发文档、API、产品能力、开发工具和接入流程。标准“文档中心页”适合承载目录、搜索、文档入口和相关资源，但首页还需要 Hero、能力导航、解决方案和平台支持模块，因此采用“文档中心页扩展”的门户结构。

## 2. Target Theme

- Theme: yeepay-开放平台-DESIGN
- Theme Source: `specs/themes/yeepay-开放平台-DESIGN.md`

## 3. Page Structure

1. 顶部全局导航
2. Hero 首屏与核心搜索
3. 快捷入口区
4. 开放能力分类区
5. 行业解决方案区
6. 开发者资源区
7. 接入流程区
8. 平台优势区
9. 最新更新与公告区
10. 帮助支持与咨询区
11. 页脚导航

## 4. Module Design

### 顶部全局导航

- Purpose: 提供 YOP 平台全局导航和高频入口。
- Content: 易宝支付 / YOP Logo、首页、解决方案、产品文档、API 文档、开发者工具、帮助中心、控制台、登录 / 用户信息。
- Actions: 切换导航、进入控制台、登录、打开移动端菜单。
- States: 默认、Hover、当前激活、未登录、已登录、移动端收起。
- Notes: 导航使用 YOP 轻量横向顶部导航；当前项使用品牌蓝文字或下划线，不使用后台侧边栏结构。

### Hero 首屏与核心搜索

- Purpose: 建立平台定位，并让开发者快速开始查找能力。
- Content: 主标题“易宝支付 YOP 开放平台”、副标题、核心 CTA、全站搜索框、热门搜索词、AI 猫头鹰或轻量平台形象。
- Actions: 开始接入、查看 API 文档、搜索关键词、点击热门词。
- States: 搜索输入中、搜索建议展开、搜索无结果、搜索失败。
- Notes: Hero 保持全宽浅色背景和充足留白。品牌蓝只用于主 CTA、关键词链接和少量强调。文案示例：“聚合易宝支付开放能力，帮助开发者快速完成支付接入、联调与上线。”

### 快捷入口区

- Purpose: 承接首屏高频路径，减少用户查找成本。
- Content: API 文档、产品文档、接入指南、SDK 下载、沙箱联调、错误码查询。
- Actions: 点击进入对应页面。
- States: 默认、Hover、New / Updated 标识、权限受限。
- Notes: 使用 2 行以内说明文案，入口数量控制在 6 个以内，避免首屏后信息过散。

### 开放能力分类区

- Purpose: 展示易宝开放能力地图，帮助用户按业务目标找产品。
- Content: 支付收单、账户体系、分账结算、企业付款、跨境支付、营销与会员、风控与安全、对账与报表。
- Actions: 查看产品、查看 API、收藏或复制文档链接。
- States: 推荐、新增、已更新、即将上线。
- Notes: 每个能力卡片包含名称、描述、标签、入口。推荐能力可有轻量品牌蓝强调，但同组卡片应保持统一高度和对齐。

### 行业解决方案区

- Purpose: 面向商户、SaaS、ISV 和渠道服务商展示按行业组织的接入路径。
- Content: 零售餐饮、电商平台、航旅酒旅、教育培训、医疗医美、供应链、SaaS 服务商、渠道伙伴。
- Actions: 查看方案、查看推荐产品、联系咨询。
- States: 默认、Hover、方案不可用。
- Notes: 不做营销落地页式夸张视觉，保持开放平台信息分发效率。每个方案说明“适用对象 + 推荐能力 + 接入入口”。

### 开发者资源区

- Purpose: 集中提供开发者接入所需的工具和技术资料。
- Content: SDK、示例代码、签名验签、回调通知、沙箱环境、YOP-MCP、Postman 集合、常见问题。
- Actions: 下载 SDK、复制示例、查看指南、进入工具页。
- States: 版本更新、下载失败、资源维护、权限受限。
- Notes: 资源项应标明语言或类型，例如 Java SDK、PHP SDK、Node.js 示例、RSA 签名指南。代码类资源应预留复制能力。

### 接入流程区

- Purpose: 让新用户理解从评估到上线的完整路径。
- Content: 了解产品、申请入驻、创建应用、配置密钥、接口联调、上线验收、生产运行。
- Actions: 查看接入指南、进入控制台、联系支持。
- States: 当前步骤、已完成、待处理、需登录、需开通。
- Notes: 使用 Steps 结构，步骤文案偏操作导向。每一步提供相关文档链接，避免只展示静态流程。

### 平台优势区

- Purpose: 建立金融科技开放平台可信感。
- Content: 统一开放能力、稳定交易服务、完整开发工具、行业接入经验、安全合规能力、持续更新支持。
- Actions: 查看平台能力、查看安全说明、查看服务支持。
- States: 默认。
- Notes: 控制文案密度，避免空泛宣传。每个优势点最好绑定用户实际收益，例如“减少联调排查时间”“统一管理应用和密钥”。

### 最新更新与公告区

- Purpose: 提醒用户关注文档、接口、SDK 和环境变更。
- Content: API 更新、SDK 版本、文档变更、沙箱维护、生产环境公告。
- Actions: 查看详情、订阅更新、进入更新日志。
- States: 普通、重要、新增、维护提醒、空状态。
- Notes: 重要公告可使用 `alert-orange` 标签，但不大面积使用橙色。列表展示标题、类型、日期和简短摘要。

### 帮助支持与咨询区

- Purpose: 为无法自行完成判断或接入的用户提供明确支持路径。
- Content: 工单支持、FAQ、商务咨询、接入问题排查、客服电话、合作申请。
- Actions: 提交工单、联系咨询、查看 FAQ、查看排障指南。
- States: 未登录提交工单、咨询入口加载失败、权限不足。
- Notes: 主入口不超过 3 个，避免把帮助区做成复杂表单。文案直接说明用户能获得什么帮助。

### 页脚导航

- Purpose: 提供平台全局底部信息和合规入口。
- Content: 产品文档、API 文档、开发工具、解决方案、帮助中心、关于易宝、备案和版权信息。
- Actions: 跳转链接。
- States: 默认。
- Notes: 保持简洁，文字颜色弱化，不喧宾夺主。

## 5. Query Fields

| Field | Component | Description | Default |
|---|---|---|---|
| 全站搜索 | Search | 搜索产品、API、错误码、SDK、接入问题 | 空 |
| 热门关键词 | Tag / Link | 推荐高频搜索词 | 小程序支付、分账、RSA 签名、回调通知 |
| 能力分类筛选 | Tabs | 在开放能力区切换能力分组 | 全部 |
| 资源类型筛选 | Tabs | 在开发者资源区切换 SDK、示例、工具、指南 | 全部 |

## 6. Table Fields

| Column | Data Key | Description | Render Rule |
|---|---|---|---|
| 标题 | title | 公告或更新标题 | 文本链接，重要公告前置 |
| 类型 | type | API 更新、SDK、文档、维护 | 使用 Tag |
| 摘要 | summary | 更新内容摘要 | 最多两行，超出省略 |
| 日期 | date | 发布时间或更新时间 | YYYY-MM-DD |
| 操作 | action | 查看详情 | 文本链接 |

## 7. Form Fields

| Field | Component | Required | Validation |
|---|---|---|---|
| 搜索关键词 | Search Input | No | 最多 50 字，去除首尾空格 |
| 咨询手机号 | Input | Yes, when consultation form is opened | 中国大陆手机号格式 |
| 公司名称 | Input | Yes, when consultation form is opened | 2-60 字 |
| 咨询内容 | Textarea | No | 最多 300 字 |

## 9. Status Design

| Status | Display | Available Actions |
|---|---|---|
| 推荐 | 蓝色弱强调 Tag 或“推荐”文字 | 查看产品、查看 API |
| 新增 | 橙色 NEW Badge | 查看详情 |
| 已更新 | 中性 Tag + 更新时间 | 查看更新记录 |
| 维护提醒 | 橙色提醒 Tag | 查看公告 |
| 即将上线 | 灰色 Tag | 预约咨询、关注更新 |

| 未登录 | Login Prompt | 登录、查看公开文档 |

## 10. Interaction Rules

- 顶部导航在桌面端横向展示，在移动端收起为菜单。
- Hero 搜索支持输入建议，建议内容按产品、API、错误码、文档分组。
- 搜索提交后进入搜索结果页，并保留关键词。
- 热门关键词点击后直接触发搜索或进入对应文档。
- 能力卡片点击标题进入产品文档，点击“查看 API”进入 API 列表或 API 文档中心。
- 控制台、密钥、沙箱联调等受限入口在未登录时先引导登录。
- 权限不足时不应直接报错，应解释原因并给出申请开通或联系支持入口。
- 开发资源下载失败时提示重试，并保留文档链接。
- 公告区重要信息置顶，维护提醒必须可进入详情。
- 所有主要链接和按钮需要具备 Hover、Focus 和键盘可访问状态。

## 11. Empty / Loading / Error

### Loading

- 首页首屏优先渲染导航、Hero 和搜索框，能力卡片和公告可使用骨架屏。
- 搜索建议加载时在下拉层展示轻量 loading。
- 公告区加载时展示 3 行骨架内容，避免页面跳动。

### Empty

- 搜索无结果：展示“未找到相关内容”，并推荐热门关键词、API 分类和帮助中心。
- 公告为空：展示“近期暂无重要更新”，保留“查看历史更新”入口。
- 资源为空：展示“当前分类暂无资源”，提供返回全部资源的操作。

### Error

- 搜索失败：提示“搜索服务暂不可用，请稍后重试”，保留用户输入。
- 资源下载失败：提示“下载失败，请重试或查看在线文档”。
- 权限不足：提示“当前账号暂未开通该能力”，提供申请开通或联系支持入口。
- 控制台入口异常：提示“控制台暂时无法打开”，提供帮助中心入口。

## 12. Theme Application

说明本页面如何应用当前主题规范。

- 使用 `yeepay-开放平台-DESIGN` 的 Light Mode 开放平台视觉规则。
- 品牌主色使用 `#1162e6`，仅用于主 CTA、激活导航、关键链接和少量强调。
- 页面主背景以白色为主，弱分区使用 `#f2f1f4`。
- 中文正文、导航、按钮和卡片文案使用 PingFang SC；英文展示标题如 YOP 可使用 Montserrat。
- 页面采用横向顶部导航、全宽 Hero、结构化内容区和轻量卡片。
- 卡片圆角优先使用 16px，大多数控件使用 8px，标签使用 3px / 4px。
- 不混用 Boss Ledger 的运营后台侧边栏、查询表单堆叠、密集表格布局或后台页面主色。
- 具体颜色、间距、导航、Tabs、搜索区、卡片区、公告区和状态表现以当前 theme 为准。
