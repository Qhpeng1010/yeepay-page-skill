# Changes Directory

Create one directory under `changes/` for every product requirement handled by this skill.

Recommended naming:

```text
YYYYMMDD-short-feature-name
```

Each change directory should contain the generated artifacts for that requirement:

```text
proposal.md
page-design.md
tasks.md
implementation.md
review.md
```

Keep each change focused on one requirement. When a change is completed, deprecated, or superseded, move it to `archive/` only when explicitly requested.
