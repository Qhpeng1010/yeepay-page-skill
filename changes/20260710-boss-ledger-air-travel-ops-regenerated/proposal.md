# 航旅机票经营与订单运维页面方案（重新生成）

## 需求名称

新增航旅机票经营总览与全部机票订单运维页面。

## 一句话需求

用户要求使用 `yeepay-page-skill` 新建目录并重新生成两个 Boss Ledger 后台功能页面：`航旅经营总览 / 航旅数据大盘首页` 和 `机票订单运维管理 / 全部机票订单列表`。本次产出为完整页面生成，包含产品方案、页面设计、任务拆解、实现说明、HTML 预览和自检结果，不包含生产项目源码接入。

## Selected Theme

- Selected theme: Boss Ledger
- Theme source: `specs/themes/boss-ledger.md`
- Routing reason: 需求属于航旅运营后台、数据首页、订单查询列表和批量运维管理场景。
- Theme boundary: 本次未读取或混用 `specs/themes/yeepay-开放平台-DESIGN.md`。

## 业务对象

- 主对象：机票订单、航旅经营指标。
- 关联对象：PNR 编码、航司航班、航线、乘客、分销渠道、机票政策、退票单、渠道账单、航班异动工单。

## 用户角色

- 航旅运营人员：查看经营大盘、识别渠道和航线表现、处理业务待办。
- 机票订单运维人员：查询订单、人工出票、改签、退票、作废、补发行程单和发送通知。
- 财务 / 对账人员：关注渠道账单、成交金额和对账待办。

## 业务目标

- 在航旅数据大盘中集中展示交易额、出票量、退改率、平台毛利润、趋势、渠道占比、航线排行和待办。
- 在全部订单列表中支持多维筛选、周期统计、单行处理和批量操作，减少订单异常漏处理。

## 功能范围

包含：

- 数据大盘筛选：时间、航线类型、国内 / 国际、渠道。
- 数据大盘指标：当期机票总交易额、出票量、退改率、平台毛利润及环比涨跌。
- 图表模块：出票量 & 交易额趋势、渠道出票占比、国内 / 国际营收占比、热门航线营收排行、高利润机票政策排行。
- 待办模块：待审核退票单、待补录 PNR 订单、待对账渠道账单、航班异动待处理工单。
- 订单列表筛选：订单状态、航线类型、航司、起降日期、乘客姓名、订单号、PNR 编码、渠道。
- 订单统计：总订单数、成功出票数、退票单数、改期单数、废票数量、总成交金额。
- 订单表格字段、单行操作、批量操作、列设置、分页、详情抽屉。

不包含：

- 不包含真实接口联调。
- 不包含生产路由、权限和菜单注册。
- 不包含真实出票、退票、改签、短信、行程单打印接口。
- 不包含复杂审批流和财务对账后端规则。

## 核心操作

- 查 询：订单列表筛选区触发，刷新列表数据。
- 重 置：清空筛选条件并恢复默认查询范围。
- 查看订单详情：行内主操作，打开右侧 Drawer。
- 人工出票 / 手动改签：行内高频操作，预留任务派发反馈。
- 发起退票 / 作废订单：行内更多操作，使用确认弹窗。
- 补发行程单 / 发送航班通知短信：行内更多操作，提交补发任务。
- 批量导出订单 / 批量改签 / 批量退票 / 批量打印行程单 / 批量补发通知：表格工具栏批量入口。

## 页面类型

- 页面 1：Dashboard / 数据首页。
- 页面 2：卡片汇总查询列表页。
