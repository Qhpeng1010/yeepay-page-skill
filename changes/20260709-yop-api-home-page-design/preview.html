统一支付下单

可用
yop.pay.order.create

创建一笔支付订单，支持收银台、扫码、快捷、网银等多种支付方式。

查看文档调试接口申请接入

退款申请

可用
yop.refund.apply

对已支付订单发起全额或部分退款，支持退款结果查询和结果通知。

查看文档调试接口申请接入

分账结果查询

Beta
yop.divide.query

查询分账订单处理结果，支持按业务请求号或易宝分账单号查询。

查看文档申请试用

商户创建

可用
yop.merchant.create

提交商户主体、结算、联系人、资质等基础信息，发起入网流程。

查看文档示例代码申请接入

账单文件下载

可用
yop.bill.download

按日期下载交易账单、结算账单或差错账单，便于系统对账。

查看文档下载示例
