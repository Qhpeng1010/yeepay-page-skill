# Page Design: Boss Ledger 跨境旅游业务运营后台

## 1. Selected Page Template

- Template: 带查询统计的查询列表页 + 审核处理页 + Drawer 详情 + Modal 处理表单
- Reason: 当前需求以订单查询、履约处理、材料审核、支付异常核验为核心，后台用户需要在列表中筛选、查看详情并执行处理动作。订单、资源履约、支付流水适合查询列表页；游客材料适合审核处理页；订单详情、日志、凭证、支付明细适合 Drawer；驳回、转人工、异常核验适合 Modal。

## 2. Target Theme

- Theme: Boss Ledger
- Theme Source: `specs/themes/boss-ledger.md`

## 3. Page Structure

1. Boss Ledger 固定框架层：顶部信息栏、一级导航、左侧导航、Tabs 页面标题区。
2. 内容区：按当前 Tab 渲染查询区、统计摘要、列表表格、分页、处理入口。
3. 辅助浮层：订单详情 Drawer、操作日志 Drawer、凭证交付 Drawer、材料审核 Modal、补材料通知 Modal、支付异常核验 Modal。
4. 平台 footer：位于内容滚动区末尾。

## 4. Module Design

### 订单运营

- Purpose: 为运营人员提供跨境旅游订单统一查询、状态追踪、风险识别和操作日志查看入口。
- Content: 查询条件包括订单编号、游客手机号、目的地、出行日期、订单状态、风险等级、产品类型、供应商；统计包括订单总量、临近出行风险、凭证待交付、材料待补、支付异常；表格展示订单编号、游客信息、产品目的地、出行日期、订单状态、风险等级、履约状态、支付状态。
- Actions: 查 询、重 置、下载Excel、查看详情、跟踪状态、查看日志。
- States: 待确认、材料待补、凭证待交付、待出行、已完成、已取消；无风险、低风险、中风险、高风险。
- Notes: 行内主操作为查看详情；跟踪状态和查看日志为普通文字按钮；超过 3 个操作时使用更多收纳。

### 资源履约

- Purpose: 监控供应商确认结果，集中处理确认失败、确认超时、人工确认和凭证交付。
- Content: 查询条件包括订单编号、供应商、确认状态、凭证状态、出行日期、超时时长；统计包括待确认、确认失败、确认超时、人工确认中、凭证待交付；表格展示订单编号、供应商、确认状态、确认次数、超时时长、失败原因、凭证状态、出行日期。
- Actions: 查 询、重 置、下载Excel、重试确认、转人工、交付凭证、查看回执。
- States: 待确认、确认成功、确认失败、确认超时、人工确认中；未交付、交付中、已交付、交付失败。
- Notes: 确认失败和确认超时处理必须记录处理备注；转人工和凭证交付需要二次确认或 Drawer 表单。

### 游客材料

- Purpose: 支持按订单和游客维度查看材料、下载材料、审核通过、审核驳回和补材料通知。
- Content: 查询条件包括订单编号、游客姓名、证件号、材料状态、材料类型、出行日期；统计包括待上传、待审核、审核驳回、待补材料、已通过；表格展示订单编号、游客信息、证件信息、材料类型、材料状态、提交时间、审核人、审核结果。
- Actions: 查 询、重 置、批量下载材料、查看材料、审核通过、审核驳回、补材料通知。
- States: 待上传、待审核、审核通过、审核驳回、待补材料。
- Notes: 审核驳回必须填写驳回原因；补材料通知需要选择材料项和通知渠道。

### 支付与汇率

- Purpose: 支持财务和风控查看支付流水、多币种金额、汇率、锁汇记录、服务费、汇差，并处理支付异常。
- Content: 查询条件包括支付单号、订单编号、支付币种、支付状态、锁汇状态、支付时间、异常类型；统计包括支付成功金额、异常待核验、锁汇失败、服务费合计、汇差合计；表格展示支付单号、订单编号、币种、原币金额、人民币金额、汇率、锁汇状态、服务费、汇差、支付状态。
- Actions: 查 询、重 置、下载Excel、查看流水、查看锁汇记录、异常核验。
- States: 支付成功、支付处理中、支付失败、退款中、已退款、异常待核验；未锁汇、已锁汇、锁汇失败、已释放。
- Notes: 异常核验属于财务 / 风控敏感操作，必须二次确认并写入操作日志。

## 10. Interaction Rules

查询条件超过 6 个时默认收起展示前 5 个字段，展开 / 收起、重 置、查 询位于三列查询网格最右侧。列表统计超过 3 个时位于表格模块内部顶部，使用 Ant Design Statistic 均分展示。表格右侧工具区保留一个主按钮 `下载Excel`，列设置使用 `SettingOutlined` icon-only Dropdown。表格行内操作必须有且只有一个主操作，其他操作为普通文字按钮或“更多”收纳。

详情查看默认使用 Drawer，不打开新页面。订单详情 Drawer 分组展示订单基础信息、履约轨迹、游客材料、支付汇率和操作日志。审核驳回、转人工确认、凭证交付、支付异常核验使用 Modal / Drawer，风险操作二次确认并记录日志。操作成功使用 message 成功反馈，失败保留当前上下文。

## 11. Empty / Loading / Error

### Loading

查询、下载Excel、重试确认、转人工、凭证交付、审核、补材料通知、异常核验进入 loading 状态；表格使用 Ant Design Table loading，按钮使用 Button loading。

### Empty

查询无结果时 Table 展示 Empty；统计为 0 时保留统计项并展示 0；Drawer 内无日志时展示“暂无操作日志”。

### Error

供应商确认失败、材料下载失败、审核提交失败、支付异常核验失败时使用 message.error 或 notification 展示原因。网络错误时提示“当前网络异常，请稍后重试”，并保留查询条件。

## 12. Theme Application

- 使用 Boss Ledger 主色 `#F36046`、内容背景 `#F4F4F4`、顶部信息栏 `#3A3A3A`。
- 保留顶部信息栏、一级导航、左侧导航、Tabs、内容区和 footer。
- 不新增营销 hero、装饰 banner、快捷入口或卡片套卡片。
- 查询区、统计区、表格区、Drawer、Modal、Dropdown、Pagination 均使用 Ant Design 真实组件或平台封装形态。
- 所有中文按钮遵守两个汉字加空格规则，如 `查 询`、`重 置`。
- 所有表单控件显式设置中文 placeholder。
- 金额列右对齐并使用 `(元)` 单位写在表头中。
