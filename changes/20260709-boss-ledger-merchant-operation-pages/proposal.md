# Proposal: Boss Ledger 商户经营与核销管理页面

## 1. Original Request

使用 yeepay-page-skill，帮我新增一个 Boss Ledger 商户资料审核页面。

详细要求包含三个一级导航：经营总览、订单核销管理、门店与渠道管理；共六个页面：经营首页数据大盘、客流经营分析、全部订单列表、券码核销工作台、门店信息管理、分销渠道管理。

## 2. Requirement Understanding

本次按用户详细功能清单落地为 Boss Ledger 商户经营后台页面组，而不是单一“商户资料审核”列表页。页面用于商户运营人员查看经营数据、分析客流、管理订单核销、维护门店和分销渠道。

## 3. Target Theme

- Theme: Boss Ledger
- Reason: 需求明确包含 Boss Ledger、经营后台、订单核销、门店管理、渠道管理等运营后台关键词，按主题选择规则使用 `specs/themes/boss-ledger.md`。

## 4. Background

商户侧经营管理需要把营收、客流、订单核销、门店和渠道数据集中到统一后台，减少跨系统查询和人工汇总。Boss Ledger 的页面应保持中高密度、稳定、可扫描，支持运营人员高频查询、导出和处理异常。

## 5. Goals

- 提供商户经营数据总览，支持按时间、品类和门店定位经营变化。
- 提供客流分析能力，辅助运营判断渠道、地域和套餐复购效果。
- 提供订单查询和批量处理能力，覆盖退款、改期、短信补发和导出。
- 提供券码核销工作台，支持扫码、手输、实时流水和异常拦截台账。
- 提供门店和渠道管理入口，支持启停、子账号、分佣、上下架和结算操作。

## 6. Users / Roles

- 商户运营人员：查看经营数据、处理订单和核销异常。
- 门店管理员：查看门店数据、执行券码核销、管理核销子账号。
- 财务人员：关注待结算款项、佣金、渠道对账结算。
- 系统管理员：维护门店、渠道、分佣比例和权限配置。

## 7. Scope

### In Scope

- 三个一级导航和六个页面的信息架构。
- 每个页面的筛选、统计、图表、表格和核心操作。
- 查询、重置、导出、批量处理、弹窗、抽屉、列设置等预览交互。
- Boss Ledger 固定框架：顶部信息栏、一级导航、左侧导航、Tabs、内容区、footer。

### Out of Scope

- 真实扫码硬件、摄像头或扫码枪接入。
- 后端接口、权限系统、短信网关、支付退款接口联调。
- 真实接口和正式工程内的 Ant Design Charts 打包配置。
- 正式 React + TypeScript 工程代码落库。

## 8. Business Object

经营指标、客流分析记录、订单、券码核销流水、异常核销记录、门店、核销子账号、分销渠道、渠道商品和渠道结算单。

## 9. Core Workflow

1. 用户进入 Boss Ledger 后台，选择一级导航和左侧页面。
2. 在查询区设置时间、门店、渠道、状态等条件。
3. 查看当前页面统计、趋势图、排行或列表。
4. 对订单、券码、门店或渠道执行单条操作或批量操作。
5. 高风险操作通过确认弹窗二次确认，成功后给出反馈并保留当前上下文。

## 11. Status

| Status | Meaning | Available Actions |
|---|---|---|
| 待核销 | 订单券码未使用 | 查看详情、改期、退款、补发核销短信 |
| 已核销 | 订单已完成核销 | 查看详情、退款 |
| 已退款 | 订单已退款完成 | 查看详情 |
| 已过期 | 订单超过有效期 | 查看详情、退款 |
| 核销成功 | 券码完成核销 | 查看流水 |
| 核销异常 | 过期、重复或无效券被拦截 | 查看异常、导出台账 |
| 营业中 | 门店正常营业 | 编辑、暂停营业、配置子账号、查看数据 |
| 暂停营业 | 门店暂停对外售卖或核销 | 编辑、恢复营业 |
| 合作中 | 渠道可售卖商品 | 修改分佣、上下架商品、对账结算 |
| 暂停合作 | 渠道暂不可售卖 | 修改分佣、恢复合作 |

## 12. Permissions

- 经营数据查看：商户运营、门店管理员、财务人员可查看授权范围内数据。
- 导出报表和台账：需要运营主管或财务权限。
- 退款、批量退款、渠道结算：需要二次确认，正式系统可叠加短信或密码校验。
- 门店启停、渠道分佣修改、商品上下架：需要管理员权限并记录操作日志。

## 13. Edge Cases

- 查询无结果时展示空状态，不清空查询条件。
- 图表运行时加载失败时展示说明，不影响表格和统计数据查看。
- 批量操作未选择记录时提示先选择数据。
- 订单已退款或已过期时禁用不适用操作。
- 门店已暂停营业时不可配置为核销门店。
- 分佣比例超出允许范围时阻止保存。
- 状态已被他人修改时提示刷新后重试。

## 14. Acceptance Criteria

- 一级导航包含经营总览、订单核销管理、门店与渠道管理。
- 六个页面均可通过左侧导航进入，Tabs 标题随页面切换。
- 每个页面包含需求指定的筛选、统计、图表、列表或操作模块。
- 列表类页面支持查询、重置、列设置、分页、导出和行内操作。
- 高风险操作具备二次确认或表单校验。
- 预览页面符合 Boss Ledger 主题，不混用 YOP 或营销化页面风格。

## 15. Assumptions

- 用户标题中的“商户资料审核页面”与详细功能清单不一致，本次以详细功能清单为准，作为“商户经营与核销管理页面组”实现。
- 默认日期以 2026-07-09 为当前业务日期。
- 预览数据为 mock 数据，仅用于页面评审。
- Boss Ledger Logo 使用现有预览占位 SVG，正式项目应替换官方品牌资产。
